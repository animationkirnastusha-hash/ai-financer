# PACK 219 — Home goal floating widget

## Цель

Убрать цель с главной из отдельного layout-блока и сделать её аккуратным плавающим элементом, который не занимает место в потоке страницы и не раздувает верх главной.

## Что изменено

- Виджет цели вынесен из `app-home-planning-row`.
- Блок ближайших платежей остался обычным контентным блоком.
- Цель теперь находится в `app-home-floating-goal-slot` внутри главной страницы.
- Виджет цели стал компактнее: меньше ширина, высота, кольцо и подписи.
- Для узких экранов добавлены адаптивные режимы: сначала компактная карточка, затем маленькое кольцо без текста.
- Нажатие по цели по-прежнему открывает страницу целей.
- Выбор цели на странице целей не менялся.

## Изменённые файлы

- `frontend/src/pages/dashboard/DashboardPage.tsx`
- `frontend/src/app/styles/pages/dashboard/home-planning-widgets.css`
