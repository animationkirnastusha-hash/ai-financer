# PACK 197 — First-run AI sequence without frontend parsers

## Цель

Убрать ручной frontend-разбор первого счёта и начального баланса из чата новичка.

## Что изменено

- Удалены функции ручного разбора первого счёта, суммы и команд пропуска баланса из `TextChatOverlay.tsx`.
- Первый запуск теперь работает как последовательность вопросов Фины:
  1. Фина просит включить микрофон или отменить.
  2. После выбора спрашивает название первого счёта.
  3. После ответа спрашивает начальный баланс.
  4. Ответ отправляется в обычный AI-flow через planner/tool contract.
- Начальный баланс можно пропустить отдельной кнопкой, без разбора текста регулярками.
- Frontend больше не создаёт счёт и операцию напрямую через `createAccount` / `createTransaction` в onboarding-чате.
- Состояние быстрого запуска хранит только черновое название счёта до отправки AI-команды.
- Добавлен отсутствующий `reports.css`, чтобы CSS audit не падал на пропавшем импорте.

## Проверка

```bash
cd /root/ai-financer/frontend
rm -rf dist
npm run build
npm run audit:css
npm run audit:predeploy:strict
```

## Ручной сценарий

1. Открыть приложение новым пользователем.
2. Фина пишет приветствие и предлагает микрофон.
3. Выбрать микрофон или отмену.
4. Фина спрашивает название первого счёта.
5. Написать только название, например `Карта`.
6. Фина спрашивает баланс.
7. Написать сумму или нажать `Пропустить баланс`.
8. Дальше создание должно пройти через обычный AI-flow, без frontend-парсера.
