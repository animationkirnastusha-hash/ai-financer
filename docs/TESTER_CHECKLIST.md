# Ai-financer — чек-лист тестировщика

Перед тестом полностью закройте Telegram и откройте Mini App заново.

## Базовый запуск

- [ ] Приложение открывается без белого/чёрного пустого экрана.
- [ ] Главная загрузилась.
- [ ] Нет технических слов в UI: backend, frontend, STT, debug, API, roadmap.
- [ ] Store виден в базовом режиме.
- [ ] Premium/Business не видны отдельными разделами без доступа.

## Счета

- [ ] Создать счёт вручную.
- [ ] Изменить название счёта.
- [ ] Изменить валюту/тип, если доступно.
- [ ] Сделать счёт основным.
- [ ] Проверить баланс на главной.

## Операции

- [ ] Создать расход вручную.
- [ ] Создать доход вручную.
- [ ] Создать перевод между счетами.
- [ ] Изменить расход: название, сумма, счёт, категория.
- [ ] Удалить расход с возвратом денег.
- [ ] Удалить расход без возврата денег.
- [ ] Операция исчезает из списка сразу после удаления.

## Категории и разделы

- [ ] Создать раздел.
- [ ] Создать категорию.
- [ ] Изменить категорию.
- [ ] Проверить, что цвет категории не меняется после добавления новых категорий.
- [ ] Проверить смысловую категоризацию: место покупки не становится названием операции.

## Главная

- [ ] Баланс отображается корректно.
- [ ] Ближайший платёж не занимает слишком много места.
- [ ] Ближайший платёж можно скрыть, если предусмотрено.
- [ ] Диаграмма расходов открывает детали.
- [ ] Заголовки не переносятся по буквам.
- [ ] Фина не перекрывает кнопки и карточки.

## Чат / текстовый overlay

- [ ] Overlay открывается поверх текущей страницы.
- [ ] Фон страницы размывается.
- [ ] Поле ввода закреплено снизу.
- [ ] После отправки клавиатура скрывается.
- [ ] Сообщения скроллятся.
- [ ] Если ушли вверх, появляется стрелка вниз.
- [ ] Confirm встроен в чат, не конфликтует с отдельной модалкой.

## Голос

- [ ] Голосовая команда запускается вручную через интерфейс.
- [ ] Слово “Фина” не обязательно.
- [ ] После команды нет дублей.
- [ ] После молчания 10–15 секунд нет самозапросов.
- [ ] Пустой звук/шум не создаёт операции.
- [ ] После ошибки голос не зависает.
- [ ] После уточнения можно продолжить сценарий.

## AI-команды

- [ ] “Расход 300 на кофе с налички” — создаёт расход без лишнего confirm.
- [ ] “Расход 3000 на продукты с карты” — создаёт расход без лишнего confirm, если всё понятно.
- [ ] “Расход 7000 на технику” — требует confirm.
- [ ] “Расход 1000 на бензин” при нескольких счетах без счёта — уточняет счёт.
- [ ] “Доход 20к на наличку” — требует confirm.
- [ ] “Создай цель отпуск 120000” — создаёт цель или показывает понятный preview.
- [ ] “Покажи категории” — открывает/показывает категории без создания лишнего действия.

## Обязательства / платежи

- [ ] Создать кредит/обязательство.
- [ ] Указать сумму платежа, дату, счёт списания.
- [ ] Проверить ближайший платёж на главной.
- [ ] Нажать “оплатил”.
- [ ] Проверить списание и историю.

## Store / Premium / Business

- [ ] Store открывается у Free.
- [ ] Premium-карточка кликабельна.
- [ ] Business не открыт без доступа.
- [ ] После выдачи Premium появляются Premium-возможности.
- [ ] После снятия Premium они скрываются.

## Админка

- [ ] Админка открывается только админу.
- [ ] Выдать Premium пользователю.
- [ ] Снять Premium.
- [ ] Выдать Business.
- [ ] Снять Business.
- [ ] Очистить финансы тестера.

## Что считать критическим багом

- Данные исчезают после плохой сети.
- Операция создаётся без подтверждения, хотя сумма крупная или смысл неясен.
- AI выполняет не то действие, которое просил пользователь.
- Голос сам создаёт действия после молчания.
- Store скрыт у Free.
- Premium/Business видны без доступа.
- Оплата/webhook работает без секрета.
