# Patch 81 — перепись голосовой системы

## Цель

Старый голосовой слой пытался держать одну длинную Web Speech сессию и перезапускать её поверх разных состояний: ожидание имени, активная команда, обработка, подтверждение, восстановление после ошибок. После нескольких успешных команд браузерный SpeechRecognition мог зависать в старой сессии, и Фина переставала реагировать.

## Новая схема

Голос разделён на два уровня:

1. `useVoiceRecognition` — низкоуровневый Web Speech adapter.
   - На каждый старт создаётся новый `SpeechRecognition` instance.
   - Старые handlers отцепляются.
   - Сессия завершается явно через `stop/cancel`.
   - Soft-errors (`no-speech`, `aborted`, `audio-capture`, `network`) не ломают цикл.
   - После блокировки/разблокировки страницы сессия сбрасывается и запускается заново.

2. `VoiceFirstCompanionLayer` — state machine Фины.
   - `passive` — микрофон слушает только имя.
   - `armed` — имя услышано, ждём задачу без повторного имени.
   - `processing` — команда отправлена в AI/backend.
   - `confirm` — есть pending confirmation.
   - `off` — голос выключен.

## Поведение

- Речь без “Фина” не отправляется в AI.
- “Фина” без команды открывает короткое активное окно.
- “Фина, кофе 300” обрабатывается как одна команда и затем возвращается в passive.
- После успешного действия Фина не продолжает отправлять случайную речь в AI.
- После каждой команды Web Speech сессия жёстко пересоздаётся, чтобы не зависать после серии команд.
- Подтверждение и отмена голосом работают через ту же pending-модалку.
